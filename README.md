# THE KARDASHEV

**Planetary Energy Intelligence System**

v0.3 features:
- Global search across pipelines, fields, refineries, plants, countries
- Region jump buttons (N. America, Middle East, Europe, Asia, S. America)
- Layer toggles + status/type filters for pipelines
- Asset browser with fly-to
- Analytics tab (production share doughnut, metrics, capacity snapshot)
- Country production markers
- Map legend
- Click any producer in the list to fly and inspect

Live: https://the-kardashev.vercel.app
