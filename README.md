# THE KARDASHEV

**Planetary Energy Intelligence System**

v0.5 focuses on OSINT-grade credibility and first-run clarity:

- Visible data vintage (“as of” date) + explicit metric definition (total petroleum liquids)
- Sources & methodology note (EIA / JODI / OPEC-aligned, curated snapshot)
- Default global aggregates so panels are never blank on load
- Event ticker tying infrastructure to recent status signals
- Colorblind-safe choropleth palette + always-visible legend
- First-visit onboarding nudge
- Open Graph meta for clean link previews
- Mobile-friendly stacked panels

Live: https://the-kardashev.vercel.app
